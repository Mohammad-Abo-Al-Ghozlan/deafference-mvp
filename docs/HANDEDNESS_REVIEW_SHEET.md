# Handedness review sheet — 50 words

Every word our lexicon is NOT confident about. Fill the last two columns.

## How to decide, in 10 seconds per word

Look up the sign, then answer ONE question: **what is the non-dominant hand doing?**

| What you see                                                | Class          | What the avatar will do           |
| ----------------------------------------------------------- | -------------- | --------------------------------- |
| Nothing — it hangs at rest, or is not used                  | **ONE-handed** | ignore it                         |
| The SAME thing as the dominant hand (same shape, both move) | **TWO sym**    | mirror the dominant hand          |
| Holds STILL as a surface/base the other hand acts on        | **TWO asym**   | put a plain flat/fist shape there |

Sources, in order of trust: **handspeak.com**, **lifeprint.com**, **signingsavvy.com**.
Avoid random YouTube uploads — often regional or wrong.

If a source shows a DIFFERENT form than another, write both in Notes and mark ?.
That disagreement is itself the finding — it means the sign has real variants and the
model will see both in the data.

# PART 2 — passive handshapes for the 35 two-handed ASYMMETRIC words

*Added 2026-08-12. Part 1 above asks **which class** a word is. This part asks a different
question for the words already classed `2a`: **what shape is the still hand, and where does
the moving hand touch it?***

## Why this exists

A `2a` sign has one hand doing the work and one hand held still as a base. Our corpus records
**one hand per participant**, so the still hand is absent from every single take — its wrist
position is tracked, but its shape never is. The avatar has to be told.

Battison's Dominance Condition narrows the choice to a closed set of seven "unmarked"
handshapes — **B, A, S, 1, 5, C, O** — but it does not say which of the seven. So each of the
35 words was assigned one, plus a **contact target**, because a handshape alone doesn't say
which *surface* the moving hand meets (a palm and a forearm are different problems for the rig).

**Everything below is a placeholder written from published descriptions, not authority.** It
unblocks the animator today; your verdict replaces it.

## How to decide, in 15 seconds per word

Look the sign up, then answer two questions about the **still** hand:

| Question | Answer goes in |
|---|---|
| What shape is it? | **our shape** column — B = flat hand · A = fist, thumb alongside · S = fist, thumb across front · 1 = index out · 5 = spread · C = curved C · O = fingertips to thumb |
| Where does the moving hand touch it? | **contact** column — `palm`, `back_of_hand`, `side_of_hand`, `forearm`, `wrist`, `thumb`, `fingers`, `fingertips`, `opening`, `under_palm`, `outline` |

If the still hand is NOT one of the seven, write what it actually is — that is a real finding,
not an inconvenience (see the first table).

Sources, same order of trust as Part 1: **handspeak.com**, **lifeprint.com**, **signingsavvy.com**.

## What each verdict changes

- **A shape change** edits `asl_handedness_250.json` → `passive_handshape.words.<word>.shape`,
  and the renderer picks the new template straight out of `handshape_templates.json`.
- **A contact change** edits the same entry's `contact`. This one matters more than it looks:
  the rig has to place the moving hand against a *surface*, and palm-vs-forearm is the
  difference between a plausible sign and a hand floating in the wrong place.
- **A shape outside the seven** means either casual signing breaks the Dominance Condition for
  that word, or our `2a` class label is wrong. Either way it goes back to Part 1 as a class
  question, so note which you think it is.
